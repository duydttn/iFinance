## Full Oral Script (Optional 2-3 Minute Version)

Good morning respected lecturers and committee members. My project is iFinance, a personal finance management and intelligent analytics system. The motivation comes from common difficulties in daily expense tracking, where users often record data inconsistently and lack actionable insights.

The objective was to develop a secure, modular, and user-friendly system that supports transaction management, category and rule-based organization, dashboard/report generation, anomaly-aware analysis, and backup/restore. The project follows an iterative engineering process including requirement analysis, architecture design, implementation, testing, and evaluation.

The architecture is layered into presentation, API, middleware, service, and data layers, which improves maintainability and scalability. The database model includes core entities such as User, Transaction, Category, Rule, AuditLog, and Setting.

Implementation results show that the system can support complete end-to-end workflows from login to report generation. Testing confirms that major functional requirements are achieved. Although current limitations include no real-time banking integration and basic forecasting capability, the system provides a strong foundation for future expansion.

In conclusion, iFinance demonstrates both practical value and academic completeness as a graduation project. Thank you, and I welcome your questions.
